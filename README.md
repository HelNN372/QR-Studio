# QR Studio 1.2

Нативное Android-приложение на русском языке. Android 8.0 и новее.

- Сканирование QR и штрихкодов камерой и с изображения, фонарик.
- Чтение EAN-13, EAN-8, UPC-A/E, Code 128/39/93, ITF, Codabar, Data Matrix, Aztec, PDF417.
- Создание QR, EAN-13, EAN-8 и Code 128; выбор формата, проверка ввода и автоматическая контрольная цифра EAN.
- Для EAN-13 введи 12 цифр (или 13 с контрольной), для EAN-8 — 7 (или 8). Code 128 поддерживает до 80 печатных ASCII-символов.
- После сканирования: содержимое, «Копировать», для HTTP/HTTPS-ссылок — «Перейти».
- Создание QR из текста, сохранение PNG через системный выбор файла, отправка в другие приложения.
- Локальная история последних 30 уникальных результатов с очисткой.
- Нет рекламы, интернет-разрешения и автоматического открытия ссылок.

## Установка
Откройте QR-Studio.apk на телефоне и разрешите установку из этого источника, если Android запросит. Камера включается автоматически при открытии приложения и вкладки сканирования. При первом запуске предоставьте разрешение. Для чтения изображения разрешение на всю галерею не требуется: используется системный выбор файла.

## Сборка
Нужны JDK 17+, Android SDK platform 35, build-tools 35.0.0, curl, zip. Задайте ANDROID_HOME и запустите ./build.sh.
ZXing Core 3.5.3 загружается с Maven Central при первой сборке; SHA-256 проверяется скриптом. Лицензия находится в libs/ZXING-LICENSE.txt. Сборка без Gradle. Ключ подписи не публикуется: скрипт создаёт локальный тестовый ключ (пароль android). Для собственного публичного релиза используйте собственный ключ. APK, собранный с новым ключом, не установится поверх оригинального релиза.

## Проверки
Пройдены 48 проверок EAN-13, EAN-8 и Code 128 (четыре поворота, инверсия, RGB и буфер камеры), проверки ввода и контрольных цифр, а также 20 проверок генерации и чтения QR (русский текст, эмодзи, URL, Wi-Fi, переносы строк, длинный текст; четыре поворота), проверки разрешённых URL; подпись APK v2/v3 проверена apksigner. Проверки камеры и интерфейса на физическом Android-устройстве не выполнялись.
